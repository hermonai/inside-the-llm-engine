\chapter{Speculative Decoding: The Draft--Verify Contract}\label{ch:speculative-decoding}

\begin{ChapterIntent}
Decode leaves compute idle, so verifying several guessed tokens in one
forward pass costs about as much as generating one. Speculative decoding
exploits this: a cheap drafter proposes tokens, the target model checks them in
parallel, and a modified rejection rule accepts them so that the output
distribution is exactly the target's. This chapter proves that exactness,
derives the expected speedup from the acceptance rate and the draft cost, and
builds drafting from n-grams, the prompt and a smaller model, including rolling
back the KV cache after a rejection.
\end{ChapterIntent}
