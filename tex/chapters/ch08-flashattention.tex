\chapter{Attention as a Memory Problem: From Online Softmax to FlashAttention}\label{ch:flashattention}

\begin{ChapterIntent}
Standard attention materializes a score matrix that grows with the square
of the sequence length and moves it through slow memory several times.
FlashAttention's insight is that attention's cost is memory traffic: with an
online softmax, attention can be computed tile by tile in on-chip memory
without ever writing the score matrix. This chapter derives the online
softmax, builds a tiled attention and checks it against a naive oracle, then
follows FlashAttention's four generations as each adapted to a new GPU ---
better parallelism, asynchrony and FP8 on Hopper, and on Blackwell a software
exponential because the tensor cores outran everything else.
\end{ChapterIntent}
