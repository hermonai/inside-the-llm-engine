\chapter{Offloading Across VRAM, RAM and NVMe}\label{ch:offloading}

\begin{ChapterIntent}
Most people run models on hardware that is too small for them. Offloading
places some layers, experts or cache blocks in host memory or on NVMe and
streams them in when needed, and then the slowest link --- PCIe or the SSD ---
sets the token rate. This chapter prices each tier by bandwidth, covers layer
offloading, CPU--GPU splits, cache and expert offloading and prefetching, and
shows how to predict the result before trying it.
\end{ChapterIntent}
