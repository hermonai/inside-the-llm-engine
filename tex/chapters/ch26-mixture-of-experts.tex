\chapter{Mixture of Experts}\label{ch:mixture-of-experts}

\begin{ChapterIntent}
A mixture-of-experts layer routes each token to a few of many feed-forward
experts, so a model can hold hundreds of billions of parameters while each
token touches only a few billion. That decouples memory capacity from
per-token bandwidth and compute --- until batching, because a batch of tokens
activates the union of their experts. This chapter derives routing, the
active-versus-total parameter split, the expert union as a function of batch
size, load balance and capacity, and the grouped GEMMs that execute experts
efficiently.
\end{ChapterIntent}
