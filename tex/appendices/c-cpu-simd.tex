\begin{ChapterIntent}

engine's scheduler. This appendix covers what matters for inference: cores and
caches, memory bandwidth per socket, SIMD from NEON and AVX2 to AVX-512, AMX
and SME, threading and NUMA, and why a well-vectorized CPU matrix--vector
product still stops at the memory bus.
