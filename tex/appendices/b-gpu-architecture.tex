\chapter{GPU Architecture for Inference Engineers}\label{app:gpu}

\begin{ChapterIntent}
The numbers this book uses --- bandwidth, peak throughput, memory
capacity, interconnect speed --- come from specific hardware structures. This
appendix explains them for inference engineers: streaming multiprocessors,
warps and occupancy; registers, shared memory, caches and HBM or GDDR; tensor
cores by generation, from Volta to Blackwell; interconnects from PCIe to
NVLink; and the corresponding structures on AMD and Apple GPUs. It ends with a
table of the devices the chapters use, each entry sourced.
\end{ChapterIntent}
