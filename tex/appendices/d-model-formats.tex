\chapter{Model File Formats: GGUF and safetensors}\label{app:formats}

\begin{ChapterIntent}
A checkpoint is a contract between training and inference. This appendix
reads the two dominant formats byte by byte --- GGUF, with its metadata and
quantized tensor types, and safetensors, with its JSON header and raw tensors
--- and shows how engines map them into memory, name tensors and check that a
file matches the architecture they implement.
\end{ChapterIntent}
