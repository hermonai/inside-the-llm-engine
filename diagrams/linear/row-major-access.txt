ROW-MAJOR GEMM ACCESS

 A [M,K] rows              B [K,N] rows              C [M,N] rows
 ┌───────────────┐         ┌───────────────┐         ┌───────────────┐
 │ Aᵢ₀ … Aᵢ,K−1 │         │ B₀₀ … B₀,N−1 │         │ Cᵢ₀ … Cᵢ,N−1 │
 └───────────────┘         ├───────────────┤         └───────────────┘
       contiguous          │ B₁₀ … B₁,N−1 │               contiguous
                            └───────────────┘

 i,j,k inner access to B:  B₀ⱼ ┄┄▶ B₁ⱼ ┄┄▶ B₂ⱼ   (stride N)
