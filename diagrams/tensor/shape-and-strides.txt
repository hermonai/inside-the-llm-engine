SHAPE AND STRIDES ANSWER DIFFERENT QUESTIONS

                   TensorView
          ┌──────────────────────────┐
          │ shape   [3, 2]           │ ──▶ which logical indices exist?
          │ strides [1, 3] elements  │ ──▶ how does each axis move in storage?
          │ base     0 elements      │ ──▶ where does this view begin?
          │ dtype    f32              │ ──▶ how are reached bytes interpreted?
          └────────────┬─────────────┘
                       │
                       ▼
          offset(i, j) = base + i × 1 + j × 3
                       │
                       ▼
             borrowed storage element

Equal shapes can carry different strides. Shape alone never proves layout.
