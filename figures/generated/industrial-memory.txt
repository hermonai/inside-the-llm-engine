EDUCATIONAL / REFERENCE

ONE DEVICE ══ weights + KV + live activations + workspace + graph + runtime
A logical pages ──▶ shared S ◀── B logical pages
A logical pages ──▶ private A; B logical pages ──▶ private B

bytes.
