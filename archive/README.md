is current policy; nothing here was deleted. Paths mirror where each file used
to live (`archive/docs/OUTLINE.md` was `docs/OUTLINE.md`), and
`scripts/check-links.py` resolves links to a moved file through this mirror,
so historical documents keep working links without being edited.
