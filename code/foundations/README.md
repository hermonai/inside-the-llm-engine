# Part I: small, inspectable computations

No model download, accelerator, framework or external Python dependency.
All weights are deterministic illustrative values, not trained parameters.
This program demonstrates computation and cache correctness, not useful
language generation or production performance.

From the repository root:

```bash
python3 -m unittest discover -s code/foundations -p 'test_*.py' -v
python3 code/foundations/lesson.py attention
python3 code/foundations/lesson.py ffn
python3 code/foundations/lesson.py decoder
```

Other topic arguments: `formats`, `numerics`, `cpu`, `gpu`, `units`,
`measurement`. Each prints the worked example from its Part I chapter.
These are arithmetic/format checks, **not measured hardware benchmarks**.
Chapters 1–8 continue to use the existing Rust engine and first-edition labs.
All lab IDs are stable even when the book's printed chapters move.

## Predict, run, explain, break

| Topic | Predict before running | Explain the output | Change one assumption |
| --- | --- | --- | --- |
| Attention | Softmax of `[0, ln(3)]` is `[.25,.75]` | A weighted sum returns `[.5,3]` | Remove the prefix slice: the future-sensitivity test fails |
| FFN | ReLU hidden row is `[1,0,2]` | Down projection returns `[1,2]`, before residual addition | Remove activation; compare a negative hidden input |
| Decoder | One evaluated token grows each layer cache by one | Full-prefix and cached logit rows match to tolerance | Reset position to zero between appends; parity fails |
| Formats | Data starts at byte 128; element (1,2) at 148 | Header-relative offsets are not file offsets | Truncate the payload; the loader rejects it |
| Numerics | Scale .5 yields codes `[-2,0,3]` | Reconstruction is approximate | Quantize 10: clipping breaks the half-step error bound |
| CPU | Nineteen values need two eight-lane groups plus three | The scalar tail cannot be discarded | Omit the tail; sum is 136 instead of 190 |
| GPU | 64/24 admits two blocks by storage alone | This is a capacity bound, not measured occupancy | Reduce storage to 16; another resource can still bind |
| Units | KV payload 960 bytes, block reservation 1536 | Capacity includes unusable tail slots | Change block size and recompute reservation |
| Measurement | TTFT 14 ms and mean token gap 11.5 ms | Timer endpoints name different events | Include terminal handling; the reported mean changes |

Make break variants in a scratch copy; restore the intended version before
committing. No benchmark result is generated by these commands.

## What the tests establish

The attention and FFN tests have hand-computed expected outputs. Decoder
tests compare full-prefix and persistent-cache control flows across MHA/GQA,
layer counts and histories; perturb future tokens; interleave independent
requests; and compare generation. Both decoder paths share scalar operators,
so their agreement alone is **not an independent proof of those operators**.
The hand fixtures supply a separate check at that level.

`model.py` uses Python float arithmetic and unit normalization gains. Weight
matrices are stored as output rows. It uses full-width split-half RoPE, causal
attention, pre-normalized residual blocks, SwiGLU and an untied output matrix.
It has no training, tokenizer, checkpoint import, paging, scheduler or HTTP
server. The existing Rust capstone adds paging and serving machinery later.
The format lesson parses only its one-tensor F32 fixture; it is deliberately
not a replacement for a maintained safetensors implementation.

## Binary model-format extension

`python3 code/foundations/gguf_bytes.py` constructs and inspects a
256-byte, two-tensor GGUF fixture in memory. It prints exact byte intervals
and decoded F32/Q4_0 values. Eleven additional tests cover every truncation
boundary, type namespaces, duplicate names, malformed dimensions, alignment,
nibble order, numerical validity and the CPU activation-rounding prediction.

The [optional ggml reference](ggml-reference/README.md) independently loads
that fixture and executes CPU graphs at a pinned upstream revision. Its
direct decoder agrees exactly, while its quantized graph demonstrates why
activation conversion is a separate numerical boundary.
